# Redesign outcomes

- [ ] The complete website uses the Editorial Coffee House visual system: espresso, oat, copper, and sage palette; Fraunces display typography; Plus Jakarta Sans UI typography; compact mono metadata; paper-grain surfaces; and responsive spacing.
- [ ] The shared shell includes an announcement strip, redesigned desktop/mobile navigation, accessible cart affordance, and a richer footer with navigation and store details.
- [ ] The homepage has an editorial split hero, clear primary and secondary CTAs, trust metrics, category discovery, featured products, and a brand story block using the existing local hero asset.
- [ ] The shop page has a redesigned heading, query/category context, filter controls, responsive grid/list presentation, stronger product cards, and a usable empty state.
- [ ] Product cards support product navigation and add-to-cart behavior while clearly presenting category, badges, price, compare-at price, weight, and description.
- [ ] Product detail, cart drawer, checkout, and admin pages inherit the redesigned visual system without breaking their existing API/state behavior.
- [ ] The application route manifest covers `/`, `/shop`, `/shop/:id`, `/checkout`, and `/admin`.
- [ ] The project builds, the preview responds with HTTP 200, and the redesign is committed and pushed to GitHub.
